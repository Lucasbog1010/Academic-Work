## Project highlights

### 1. Electronics — 8-Bit FPGA Counter

A modular digital counter designed in Verilog and implemented for the Digilent Nexys A7-100T FPGA board. The project covers clock division, counting logic, binary-to-BCD conversion, and multiplexed seven-segment display control.

**Skills:** Verilog · Vivado · FPGA · Digital electronics · Hardware implementation

[View electronics project](8-Bit-Counter-Verilog-Vivado/)

### 2. Machine Learning — Binary Classification

A classification project involving imbalanced data, comparison of machine-learning approaches, and hyperparameter optimisation. The selected model was an ExtraTrees classifier tuned using Optuna and evaluated with stratified cross-validation.

**Skills:** Python · Machine learning · Model evaluation · Statistical analysis · Optuna

[View machine-learning project](Machine-Learning-Classification-Portfolio/)

### 3. Master's Thesis — CMS Silicon Detector Noise Analysis

An investigation of common-mode noise in silicon detector modules for the CMS Outer Tracker upgrade at the High-Luminosity LHC. The work compares detector measurements across test configurations and uses statistical analysis to study noise behaviour.

**Skills:** Python · ROOT/PyROOT · Jupyter · Experimental data analysis · Semiconductor detectors

[View Master's thesis project](CMS-Silicon-Detector-Noise-Analysis/)

### 4. Materials Engineering — Two Projects

- **[Si/SiO₂ Interface Modelling](Materials-Engineering-GitHub-Portfolios/Si-SiO2-Interface-DFT/):** A computational study of the electronic properties and band offsets of a silicon/silicon-dioxide interface using density functional theory and ABINIT.
- **[Quantum Dots, Nanomaterials & Photovoltaics](Materials-Engineering-GitHub-Portfolios/Quantum-Dots-Nanomaterials-Photovoltaics/):** A literature-based study connecting nanomaterial properties to photovoltaic applications.

**Skills:** Materials science · Semiconductor physics · DFT · ABINIT · Technical research

### 5. Optics — Gemstones and Solid-State Lasers

A group technical report on the optical and electronic properties of gemstone crystals and their use in solid-state lasers, including ruby, Ti:sapphire, and alexandrite.

**Skills:** Optics · Laser physics · Functional materials · Scientific literature review · Technical reporting

[View optics project](Gemstones-and-Solid-State-Lasers-Portfolio/)
