Welcome to my academic project portfolio.
This repository brings together selected projects from my studies. They illustrate how I apply scientific reasoning and technical tools to understand systems, analyse results, and address engineering problems.

## Explore the projects

| Area | Project | What it demonstrates |
| --- | --- | --- |
| **Electronics** | [Theremin and 8-Bit FPGA Counter](https://github.com/Lucasbog1010/Academic-Work/tree/main/Electronics_Project) | Analog circuit manipulation and simulation using LTSpice. Digital design in **Verilog**, FPGA implementation with **Vivado**, and seven-segment display control. |
